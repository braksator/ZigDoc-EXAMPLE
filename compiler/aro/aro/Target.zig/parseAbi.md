# parseAbi

Parse ABI string in `<abi>(.?<version>)?` format.

Poplates `abi`, `glibc_version` and `android_api_level` fields of `result`.

If given `version_string` will be populated when `InvalidAbiVersion` or `InvalidApiVerson` is returned.
