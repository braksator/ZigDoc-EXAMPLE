# opp

The function opp negates a field element in the Montgomery domain.

Preconditions:
  0 ≤ eval arg1 < m
Postconditions:
  eval (from_montgomery out1) mod m = -eval (from_montgomery arg1) mod m
  0 ≤ eval out1 < m
