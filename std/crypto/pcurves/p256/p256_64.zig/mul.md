# mul

The function mul multiplies two field elements in the Montgomery domain.

Preconditions:
  0 ≤ eval arg1 < m
  0 ≤ eval arg2 < m
Postconditions:
  eval (from_montgomery out1) mod m = (eval (from_montgomery arg1) * eval (from_montgomery arg2)) mod m
  0 ≤ eval out1 < m
