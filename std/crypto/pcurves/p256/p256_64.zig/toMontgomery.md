# toMontgomery

The function toMontgomery translates a field element into the Montgomery domain.

Preconditions:
  0 ≤ eval arg1 < m
Postconditions:
  eval (from_montgomery out1) mod m = eval arg1 mod m
  0 ≤ eval out1 < m
