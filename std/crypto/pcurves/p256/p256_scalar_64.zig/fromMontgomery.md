# fromMontgomery

The function fromMontgomery translates a field element out of the Montgomery domain.

Preconditions:
  0 ≤ eval arg1 < m
Postconditions:
  eval out1 mod m = (eval arg1 * ((2^64)⁻¹ mod m)^4) mod m
  0 ≤ eval out1 < m
