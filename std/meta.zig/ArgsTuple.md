# ArgsTuple

For a given function type, returns a tuple type which fields will
correspond to the argument types.

Examples:
- `ArgsTuple(fn () void)` ⇒ `tuple { }`
- `ArgsTuple(fn (a: u32) u32)` ⇒ `tuple { u32 }`
- `ArgsTuple(fn (a: u32, b: f16) noreturn)` ⇒ `tuple { u32, f16 }`
