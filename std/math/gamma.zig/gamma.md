# gamma

Returns the gamma function of x,
gamma(x) = factorial(x - 1) for integer x.

Special Cases:
 - gamma(+-nan) = nan
 - gamma(-inf)  = nan
 - gamma(n)     = nan for negative integers
 - gamma(-0.0)  = -inf
 - gamma(+0.0)  = +inf
 - gamma(+inf)  = +inf
