# lgamma

Returns the natural logarithm of the absolute value of the gamma function.

Special Cases:
 - lgamma(+-nan) = nan
 - lgamma(+-inf) = +inf
 - lgamma(n)     = +inf for negative integers
 - lgamma(+-0.0) = +inf
 - lgamma(1)     = +0.0
 - lgamma(2)     = +0.0
