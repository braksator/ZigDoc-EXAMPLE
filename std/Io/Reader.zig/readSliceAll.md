# readSliceAll

Fill `buffer` with the next `buffer.len` bytes from the stream, advancing
the seek position.

Invalidates previously returned values from `peek`.

If the provided buffer cannot be filled completely, `error.EndOfStream` is
returned instead.

See also:
* `peek`
* `readSliceShort`
