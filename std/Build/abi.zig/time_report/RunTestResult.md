# RunTestResult

WebSocket server->client.

Sent after a `Step.Run` for a Zig test executable finishes, providing the test's time report.

Trailing:
* for each `tests_len`:
  * `test_ns: u64` (nanoseconds spent running this test)
* for each `tests_len`:
  * `name` (null-terminated UTF-8 string)
